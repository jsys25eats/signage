# signage

ローカル動画と Web リンクを順番に切り替えて表示するサイネージ用スイッチャー。
Cloudflare Workers + Durable Objects（無料枠）で動作し、スマホから操作できます。

- `/` … 設定画面（表示用 PC で開く）
- `/display` … 表示画面（全画面表示対応）
- `/r/<ルームID>` … スマホ用の操作画面（設定画面・空の表示画面に出る QR コードから開く）

## 機能

- 動画（ローカルファイル）を複数登録。再生が終わると次へ進む
- リンク（URL）を複数登録。アイテムごとに設定した秒数で次へ進む（既定秒数も設定可能）
- ドラッグ（⋮⋮ をつかむ）で並べ替え。最後まで行くと先頭に戻ってループ
- 各行の「⋯」メニューから「今すぐ表示 / これに固定 / 削除」
- 設定画面・スマホの変更は表示画面に即時反映（WebSocket）
- スマホから リンク追加・並べ替え・削除・秒数変更・「前へ / 次へ / ここから再生」が可能。再生中のアイテムも確認できる
- 操作用リンクは設定画面から再発行でき、古いリンクは無効になる
- 「これに固定」で特定のアイテムを表示し続ける（動画はループ）。解除するとそこから通常の順番に戻る
- 表示画面: `F` キー・ダブルクリック・ボタンで全画面、`←` `→` で前後移動
- 表示中は画面スリープを抑止（Wake Lock 対応ブラウザ）

## データの保存先

| データ | 保存先 |
| --- | --- |
| 動画ファイル | 表示用 PC のブラウザ（IndexedDB）。**サーバーには送信しない** |
| プレイリスト（動画名・リンク・秒数・順番）と設定 | Durable Object（表示用 PC ごとの「ルーム」）＋表示用 PC にキャッシュ |

- 動画の追加は、表示用 PC と **同じブラウザ（同じプロファイル）** で開いた設定画面からのみ行えます。スマホからは並べ替え・削除のみです。
- ネットが切れても、表示画面はキャッシュしたプレイリストで再生を続けます。
- ルーム ID（URL）を知っている人は誰でも操作できます。漏れた場合は設定画面の「リンクを再発行」を使ってください。

## 注意点

- 埋め込み表示（iframe）を禁止しているサイト（`X-Frame-Options` / CSP `frame-ancestors`）は表示できません。
- ブラウザの自動再生ポリシーにより、音声ありの動画は表示画面を一度クリックするまで無音で再生されることがあります。
- 再生できる動画形式はブラウザ依存です（MP4(H.264) / WebM が無難）。

## 開発

```sh
npm install
npm run dev        # Vite 開発サーバー
npm run build      # dist/ を生成
npx wrangler dev   # Workers ランタイムでローカル確認
```

## デプロイ（Cloudflare 無料枠）

### 手元から

```sh
npx wrangler login
npm run deploy
```

`https://signage.<あなたのサブドメイン>.workers.dev` で公開されます。

### GitHub Actions から（main への push で自動デプロイ）

リポジトリの Settings → Secrets and variables → Actions に以下を登録します。

| Secret | 内容 |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | Cloudflare ダッシュボードの「API トークン」で「Cloudflare Workers を編集する」テンプレートから作成 |
| `CLOUDFLARE_ACCOUNT_ID` | ダッシュボードの Workers & Pages 画面右側に表示されるアカウント ID |
